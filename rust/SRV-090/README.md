# SRV-090 Rust 시범 포팅

`python/SRV-090.py`(불필요한 원격 레지스트리 서비스 활성화 점검)를 Rust로
시범 포팅한 것입니다. 원본 Python 스크립트는 그대로 유지되며, 이 포팅이
대체하지 않습니다.

## 구성

- `Cargo.toml`: 외부 크레이트 의존성 없음 (표준 라이브러리만 사용)
- `src/main.rs`: 점검 로직. 원본과 동일한 stdout 문구/순서와 빈 SRV-090.log
  생성을 목표로 함

## 외부 명령 의존 (보존)

이 포팅은 원본과 같이 `systemctl is-active --quiet remote-registry`를
실행합니다. 외부 명령을 제거한 것이 아니라 언어만 이식한 것입니다.
또한 원본의 한계인 "명령이 비0 종료로 실패하면 서비스 비활성(양호)으로
판정"하는 동작을 그대로 보존합니다.

## 빌드 (승인 전 실행 금지 상태)

```bash
cd rust/SRV-090
cargo build --release
```

산출물: `target/release/SRV-090`

## 원본과의 동등성

목표는 원본과의 동일 동작이지만, 빌드·실행 비교는 아직 수행하지 않았습니다.
코드 검토 수준에서 확인된 차이 후보는 `src/main.rs` 상단 주석에 적혀 있습니다
(systemctl 부재 시 오류 경로 형태, 로케일/UTF-8 출력, 시그널 종료 판정
미검증).
