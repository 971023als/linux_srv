# SRV-096 Rust 시범 포팅

`python/SRV-096.py`(사용자 환경파일의 소유자 또는 권한 설정 점검)를 Rust로
시범 포팅한 것입니다. 원본 Python 스크립트는 그대로 유지되며, 이 포팅이
대체하지 않습니다.

## 구성

- `Cargo.toml`: 외부 크레이트 의존성 없음 (표준 라이브러리만 사용)
- `src/main.rs`: 점검 로직. 원본과 동일한 SRV-096.log 내용/기록 순서와
  최종 stdout 출력(로그 전체 덤프 + 추가 개행)을 목표로 함

## 빌드 (승인 전 실행 금지 상태)

```bash
cd rust/SRV-096
cargo build --release
```

산출물: `target/release/SRV-096`

## 원본과의 동등성

목표는 원본과의 동일 동작이지만, 빌드·실행 비교는 아직 수행하지 않았습니다.
가장 큰 의미 차이 후보는 계정 범위입니다: 원본의 `pwd.getpwall()`은 NSS를
거쳐 LDAP/NIS 등 외부 계정까지 포함될 수 있으나, 이 포팅은 표준
라이브러리만으로 `/etc/passwd`만 읽습니다. NSS 환경에서는 점검 대상과
소유자 이름 해석이 달라질 수 있습니다.
그 외 코드 검토 수준에서 확인된 차이 후보는 `src/main.rs` 상단 주석에 적혀
있습니다 (오류 경로 출력 형태, 로케일/UTF-8 인코딩, 사용자 순회 순서,
isfile/stat 동등성 미검증).
