# SRV-094 Rust 시범 포팅

`python/SRV-094.py`(로그 기록 정책 점검, /etc/rsyslog.conf 내용 확인)를 Rust로
시범 포팅한 것입니다. 원본 Python 스크립트는 그대로 유지되며, 이 포팅이
대체하지 않습니다.

원본의 출력 제목은 "[SRV-094] crontab 참조파일 권한 설정 미흡"이지만 실제
점검 대상은 rsyslog 설정입니다. 이 불일치는 원본 동작 그대로 보존하며,
이 포팅에서 수정하지 않습니다.

## 구성

- `Cargo.toml`: 외부 크레이트 의존성 없음 (표준 라이브러리만 사용)
- `src/main.rs`: 점검 로직. 원본과 동일한 stdout 문구/순서와 SRV-094.log 생성을
  목표로 함

## 빌드 (승인 전 실행 금지 상태)

```bash
cd rust/SRV-094
cargo build --release
```

산출물: `target/release/SRV-094`

## 원본과의 동등성

목표는 원본과의 동일 동작이지만, 빌드·실행 비교는 아직 수행하지 않았습니다.
코드 검토 수준에서 확인된 차이 후보는 `src/main.rs` 상단 주석에 적혀 있습니다
(오류 경로 출력 형태, 비UTF-8 로케일의 파일 디코딩/stdout 인코딩, 부분열
검사 동등성 미검증, exists 동등성 미검증).
