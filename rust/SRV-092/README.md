# SRV-092 Rust 시범 포팅

`python/SRV-092.py`(사용자 홈 디렉터리 설정 점검)를 Rust로 시범 포팅한 것입니다.
원본 Python 스크립트는 그대로 유지되며, 이 포팅이 대체하지 않습니다.

## 구성

- `Cargo.toml`: 외부 크레이트 의존성 없음 (표준 라이브러리만 사용)
- `src/main.rs`: 점검 로직. 원본과 동일한 stdout 문구/순서와 SRV-092.log 생성을
  목표로 함

## 빌드 (승인 전 실행 금지 상태)

```bash
cd rust/SRV-092
cargo build --release
```

산출물: `target/release/SRV-092`

## 원본과의 동등성

목표는 원본과의 동일 동작이지만, 빌드·실행 비교는 아직 수행하지 않았습니다.
코드 검토 수준에서 확인된 차이 후보는 `src/main.rs` 상단 주석에 적혀 있습니다
(오류 경로 출력 형태, 비UTF-8 로케일의 stdout 인코딩, 공백 문자 집합 미세 차이,
isdir 동등성 미검증).
